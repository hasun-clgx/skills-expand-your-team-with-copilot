# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share activities through WhatsApp, Facebook, your device's sharing menu
  (when supported), or a copied link, without logging in
- Open a shared link to jump directly to the highlighted activity

Sharing includes only the activity name, schedule, and public link, not student
details. If automatic copying is unavailable, the link is shown for manual copying.
